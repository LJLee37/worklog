# worklog

개인 작업 기록(코딩/서버 설정 등) + Claude Code 등 AI를 활용한 작업 기록을
공개로 남기는 저장소.

> ⚠️ **이 저장소는 public입니다. 민감정보(비밀번호·API 키·토큰·SSH 개인키·
> VPN/EAP 자격증명·실제 도메인이나 공인 IP·타인의 개인정보 등)는 어떤 이유로도
> 절대 커밋하지 마세요.** 기록에는 "무엇을 했는지"만 남기고, 구체적인 값은
> 남기지 않습니다. AI 세션을 위한 상세 지침은 [`CLAUDE.md`](./CLAUDE.md)에
> 있습니다.

## 구조

```
<YYYY>/<YYYY-MM-DD>.md   # 하루에 파일 하나
```

각 파일 템플릿:

```markdown
# YYYY-MM-DD

## 작업
- ...

## AI 활용
- 도구/모델: ...
- 무엇을 했는지 요약
- (필요시) 참고한 세션/저장소 링크
```

## AI 활용 작업 기록: `/log`

이 저장소에는 `.claude/commands/log.md`에 정의된 Claude Code 슬래시 명령
`/log`가 커밋돼 있습니다. 이 저장소를 열고 `/log`를 실행하면 오늘 날짜 파일에
현재 세션의 작업/AI 활용 내역을 요약해 추가합니다 — 어느 기기에서 clone해도
바로 재사용할 수 있습니다.

## 민감정보 방지 안전망

`githooks/pre-commit`에 흔한 시크릿 패턴(개인키, API 키, `password=`류 등)을
잡아 커밋을 막는 최소한의 pre-commit 훅이 있습니다. 새로 clone한 뒤에는
아래 명령으로 한 번 활성화해야 합니다 (`core.hooksPath`는 로컬 설정이라
clone 시 자동으로 따라오지 않습니다):

```
git config core.hooksPath githooks
```

**주의**: 이 훅은 흔한 패턴만 잡는 마지막 안전망이며, 민감정보를 커밋하지
않는 것은 결국 커밋하는 사람(사람이든 AI든)의 책임입니다.
