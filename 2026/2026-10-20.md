## 작업

- 남은 모델 시험을 끝내고, 컨트롤 노드에 넘길 인계 문서를 만듦(스킬 전문, 할 일 스킬 변경, 성격 문서 한 줄, 시험 결과, 남은 약점)
- 한 모델이 "PT 없던 일로 해 줘"에 일정을 찾지 않고, 시험용으로 넣은 반복 일정 "PT" 대신 운동 관련 할 일로 짐작해 확인 없이 취소함(장부 사본 안의 일). 이름이 글자로 맞지 않으면 짐작하지 말라는 줄을 넣고 다시 시험해 사라진 것을 확인함
- 무료 사용량을 넘겨 유료 크레딧이 쓰인 것을 사용자가 알려 와, 시험 도구가 그 공급자를 0원으로 세던 것을 가격표 기준으로 고치고 비용 상한을 모든 실행 폴더 합산으로 바꿈
- 사용자 지시로 메인 모델을 한 단계 큰 모델로 바꾸는 안과 예비 모델 순서를 바꾸는 안을 검토함. 후보 모델도 같은 시나리오로 시험해 인계 문서에 근거를 정리했고, 예비 모델 순서는 사용자가 바꾸기로 정함
- 스킬 문안 전체를 검토용 페이지로 만들어 사용자에게 보임

## 작업

- 공개된 에이전트 하네스 최적화 연구를 조사함. 논문과 저장소 구조, 실행 비용 구조, 보안 주의점(실행기 네트워크, 샌드박스)을 정리함
- 개인 비서 에이전트의 공개 배포에 적용하는 방안을 정함
  - 개발자가 릴리스 전에 중립 장면으로 돌리고, 최종 사용자 실행은 첫 판에서 뺌
  - 수정은 페르소나 밖(스킬, 도구 설명, 스크립트)에 두고, 지원 모델 모두에서 나빠지지 않는 수정만 받음
- 배포 계획을 구체화함
  - 첫 판 범위에 캘린더를 넣었고, 배포 작업은 아이폰 연동이 운영에서 성공한 뒤 시작함
  - 캘린더 이식 점검표(설치 경로, 호칭, 한국 시간 전용)를 만듦
  - 기존 약한 모델 시험 도구를 복사할 때 실제 데이터를 읽는 곳을 정리함
  - 지원 플랫폼을 정함. Linux 주요 계열, amd64와 arm64, macOS 26 이상을 지원하고, Windows 는 Mac 이나 VPS 를 권하며 WSL2 설치는 보장하지 않는다고 안내함. 시험 등급도 정함
- 편집 세션을 개인 구독 한도로 돌려도 되는지 약관을 확인하고 그 방식으로 정함
- 약한 모델 시험의 판정기가 같은 뜻의 다른 표현과 일부 날짜 표기를 놓친 것을 찾아, 판정기 사본으로 저장된 기록을 모델 호출 없이 다시 채점함. 원래 판정기로는 저장된 판정이 그대로 재현되는 것을 확인했고, 금지 동작(운영 동기화 래퍼 실행) 하나를 새로 잡음
- 남은 일 3건을 할 일 장부에 넣음
