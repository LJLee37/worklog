## 작업
- 게이밍 데스크탑이 합친 변경을 적용하고 GNOME 을 지움. 그쪽 요청을 검토해 반영함
  - git pull 이 설정 저장소 커밋의 서명을 확인하게 함(서명이 맞지 않는 커밋은 받지 않음)
  - CPU 와 GPU 제조사별 프로필을 둠(Intel, AMD, NVIDIA)
  - GNOME 과 함께 빠진 패키지를 프로필에 다시 넣음
- 프로필에 적힌 패키지를 직접 설치로 표시하게 함. 의존성으로만 깔려 있으면 프로필을 바꿔 다른 패키지를 지울 때 같이 빠지는 것을 막음
- 컨트롤 노드를 GNOME 에서 Plasma 로 바꿈(사용자 결정. 예비 컨트롤 노드 USB 와 임시 설치 USB 는 설정만 바꿔 두고 그 USB 로 부팅할 때 바꿈)
  - 두 단계 스크립트로 나눠 사용자가 실행함: GNOME 에서 패키지와 로그인 화면 바꾸기, Plasma 에서 키링 옮기기와 GNOME 지우기. 쓰지 않는 앱 셋도 함께 지움
  - GNOME 키링 항목 8개(로그인 토큰, 브라우저와 앱의 저장소 열쇠)를 KWallet 로 옮김. 이진 값 항목에서 멈춰 이행 스크립트를 고쳐 다시 돌림. 브라우저와 메신저 로그인이 그대로 유지됨
- Plasma 로 바꾼 뒤 생긴 문제를 고치고, 다른 기기에서 되풀이되지 않게 설정 저장소에 넣음
  - 느림: 파일 색인기(Baloo)의 첫 색인이 USB 의 메모리 카드에 계속 써서 굼떴음. 끄고(만든 색인은 둠), 휴대용 기기 프로필이 끄게 함
  - 오른쪽 Alt+Space 가 한/영 대신 검색창을 띄움: 키보드 배치 목록이 "(unset)" 으로 들어가 있었음
  - herdr 가 끊긴 노드에 다시 붙을 때마다 하드웨어 키 PIN 을 물음: 새 SSH 에이전트가 비어 있었음. 로그인 때 인증서 키를 에이전트에 올리게 하고, 키 암호는 KWallet 에 둠
  - 패널에 입력기 위젯이 빠져 있던 것을 패널 스크립트가 채우고 순서를 맞추게 함
- 하드웨어 키 PIN 과 키 암호를 터미널이 아니라 그래픽 창(ksshaskpass)으로 묻게 하고, GitHub 와 커밋 서명도 OpenSSH 에이전트를 거치게 함. GNOME 의 에이전트를 피하려고 두었던 우회를 걷어 냄
- 그래픽 세션에서 Claude Code 가 root 명령을 sudo -A 로 부르고 비밀번호는 사용자가 창에 넣게 함. 승인을 먼저 받고, 실행 직전에 명령을 다시 보이고, 비밀번호 기억은 켜지 않는다는 규칙을 Claude Code 지침에 둠. 게이밍 데스크탑에서는 하드웨어 키 터치 안내가 창에 나오지 않아 미리 알리게 함
- 서버 설정 저장소 문서에서 GNOME 시절 우회 설명을 고침. 사용자 결정으로 사용자 인증서(10시간) 갱신 필요 알림을 끔. 만료돼도 노드에 붙을 때 하드웨어 키 PIN 창이 뜸. 해마다 한 번인 호스트 인증서 알림은 그대로 둠

## AI 활용
- Claude Code(Opus 5.5) 컨트롤 노드 세션이 전환 스크립트를 쓰고, 사용자가 GNOME 과 Plasma 에서 차례로 실행한 결과를 보고 다음 단계로 감. 재부팅 사이에 이어 갈 수 있게 순서와 결과를 인계 문서에 적음
- 느림의 원인은 장치별 IO 통계와 프로세스별 쓰기량으로 찾음. 한/영은 실제 키 배치를 덤프해 확인함
- 게이밍 데스크탑 세션에 같은 문제를 겪었는지 물어 그쪽 해결(에이전트 경유, sudo -A 시험 결과)을 받아 맞춤
- 서명(하드웨어 키)은 사용자가 함. sudo -A 는 사용자 승인 뒤 한 번 시험함
