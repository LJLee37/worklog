  개발 착수 준비가 됐는지 점검.
  - 저장소 구조·설계 문서 12종·크레이트 골대(core/client/net/mod/server)를 검토.
    의존 방향이 core로만 흐르도록 구성돼 있고 전부 스텁 상태임을 확인.
  - raspi(aarch64)에서 직접 빌드 검증: `cargo check` / `cargo fmt --check` /
    `cargo clippy -D warnings` / `cargo test` / `cargo run -p driftline-client`
    전부 통과(경고 0).
  - Rust 툴체인이 이미 rustup + stable + 크로스컴파일 타깃 6개까지 설치돼 있으나
    cargo가 PATH에 없어 수동 export가 필요한 상태, Cargo.lock이 커밋되지 않은
    상태, 프로젝트가 임시 외장 디스크 마운트 지점에 위치한 점 등을 착수 전
    정리거리로 정리. 결론: M0(골격+문서) 완료, M1 착수 가능.
- 할 일 추적을 체크리스트로 정비.
  - docs/ROADMAP.md의 마일스톤 표(M0~M14)를 단순 나열에서 완료 체크 열이 있는
    형태로 변경: M0은 완료 표시, M1~M14는 미완 표시. 진행 방식 안내와 현재
    마일스톤(M1) 표시 추가.
  - docs/M1.md 신설: M1의 세부 태스크를 9개 섹션 62개 체크 항목으로 분해(개발
    환경 정리, 결정론 인프라, 리플레이 하네스+CI 활성화, 시뮬 코어 골격,
    시간 시스템, 월드 생성, 시작 시나리오, 단일 배 1층, 렌더 창, 완료 기준).
    각 항목을 기존 설계 문서(TESTING/DETERMINISM/ARCHITECTURE/WORLD)에 근거.
    마일스톤이 끝나도 이 문서는 삭제하지 않고 체크 표시만 유지하기로 함.
