## 작업
- GitHub 프로필 README를 다시 씀. 비공개 이력서 저장소의 사실 기록(작업 중인 브랜치의 커밋 안 된 정정 포함)을 근거로 초안을 만들고, 다른 세션이 올려 둔 Draft PR과 비교해 보고함. 주된 차이는 AI가 진단하고 실행한 일을 본인 성과처럼 쓴 문장, 경험 범위를 넘는 기술 항목, 가장 두꺼운 근거인 팀 프로젝트 기여가 빠진 것.
- 공개 범위를 정한 뒤(일부 소재 제외, 구직 문구와 worklog 링크 포함) 결과를 기존 PR에 커밋으로 얹고 PR 설명을 고침. merge는 아직 안 함.
- 이력서 저장소의 사실 기록에 서버 세 대 적용 확인과, FIDO2 보안 키를 CA로 한 SSH 사용자 인증서와 호스트 키 인증서 운영을 추가함. 구현은 AI, 설계 검토 두 건과 서명은 본인으로 나눠 적음. 다른 작업 브랜치들이 같은 파일의 근처를 고치고 있어, 겹치지 않는 줄만 고치고 임시 복제본에서 다섯 브랜치와 병합을 시험해 충돌이 없는 것을 확인함.

## AI 활용
- Claude Code(Opus 5.5)로 이력서 저장소와 작업 브랜치, 공개 worklog, 저장소 공개 여부를 대조해 초안과 비교표를 만듦. 본인이 확인해 준 사실(보안 키와 인증서 운영, 클라우드 노드 적용)은 반영하기 전에 worklog 기록과 커밋으로 뒷받침되는지 다시 대조함.
- 아쉬웠던 점: 첫 보고에서 보안 키 구성을 "이력서 기록에 근거가 없다"고만 적어, 사실이 아니라는 뜻으로 읽힐 여지를 남김. 기록에 없을 뿐인지, 사실 확인이 필요한지를 나눠 말했어야 함.
