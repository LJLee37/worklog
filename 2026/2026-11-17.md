## 작업
- 임시 설치 USB 의 세션이 깐 게이밍 데스크탑(Arch, Windows 와 듀얼 부팅)에서 첫 부팅 뒤 확인을 함
  - 설치 세션이 남긴 인계와 로그를 읽고, NVIDIA 드라이버와 Wayland, NTSync 를 확인함. Proton 으로 Windows 게임을 실행해 NTSync 를 실제로 쓰는 것까지 봄
  - 부트 메뉴를 다시 만들 때 한국어 로케일에서 grub-mkconfig 가 실패함(번역문의 서식을 bash printf 가 못 받음). LC_ALL=C 로 돌려 해결
  - 사용자는 Windows 쪽 시계와 최대 절전을 맞춤
- 방화벽을 켬. 들어오는 연결은 기본으로 막고, 공유기 안에서 오는 mDNS 와 Steam 원격 플레이, LAN 전송만 허용함. sshd 는 꺼 둠. 이 데스크탑은 서버 설정 저장소가 관리하지 않기로 함(사용자 결정)
- 이 기기의 Claude Code 지침과 mod 를 깖. 다른 세션이 요청한 설정이라 내용을 보이고 사용자 승인을 받은 뒤 깖
- AirPlay 수신기를 만듦
  - 저장소 판이 오래돼 nqptp 와 shairport-sync 새 판을 직접 빌드함. 방화벽은 공유기 안에서만 엶. 첫 재생 전에 청력 안전(음량이 늘 100% 디지털로 나가고 DAC 에서만 조절됨)을 안내함
  - 실측해 보니 iOS 27 은 무손실 곡도 AirPlay 2 로는 AAC 48kHz 로 보냄. 클래식 AirPlay 수신기를 하나 더 두어 ALAC 16bit/44.1kHz 무손실로 받는 것을 확인함
  - 둘의 차이를 느끼기 어려워 AirPlay 2 하나만 남김(사용자 결정)
- GNOME 옆에 Plasma 6 를 시험으로 깖(고른 KDE 앱과 구성요소)
  - 로그아웃해도 herdr 와 Claude 세션이 살아 있게 linger 를 켬(사용자 결정)
  - Plasma 에서 한글 입력(IBus)을 맞춤
  - linger 때문에 로그아웃 뒤 AirPlay 수신기가 다시 뜨지 않아, 소리 서비스와 함께 켜지고 꺼지게 함
