## 작업

- 같은 최종 시험 조건(최종 인격 설정, 할 일 스킬, 예약 도구, 실제 오류 문구)으로 설정 12개를 더 돌렸다. 기존 후보의 추론 강도를 높인 설정, 이틀 전 새로 나온 모델, 더 비싼 상위 모델들이다. 실행 전 기존 실측 사용량으로 설정별 비용을 추정하고, 공급자별 예산 상한을 걸어 돌렸다.
- 18개 설정을 한 장면에 섞어 채점해 보니, 가장 강한 모델이 섞이면 나머지 점수가 0.15~0.25 내려갔다. 강한 설정을 빼고 12개로 다시 채점했고, 순위는 거의 같았다(순위 상관 0.965). 추론 강도를 올려도 점수는 거의 같고 응답만 2~4배 느려졌다.
- 세 번째 공급자의 모델 2개를 추가로 시험했다. 시험 틀에 그 공급자의 API 경로를 새로 붙였다. 실제 비서 프로그램은 빈 답을 받으면 같은 요청을 최대 3번 다시 보내는데 시험 틀에는 이 동작이 없는 것을 찾아, 새 경로에 같은 재시도를 넣고 해당 답만 다시 돌렸다. 기존 후보 4개를 기준으로 함께 채점했다.
- 결과를 장면별로 비교하는 페이지 3개를 만들었다(설정별 요약표, 장면별 평균표, 답과 채점 이유).
- 최종으로 새로 나온 모델(중간 추론 강도)을 대화 모델과 예약 작업 모델로, 세 번째 공급자의 가벼운 모델을 예비 모델로 정했다. 컨트롤 노드 인계 문서를 새로 쓰고 예전 인계 문서 두 개에는 대체됐다고 표시했다(적용은 아직). 비서 프로그램 판이 새 모델보다 오래돼 실제 호출 확인을 인계에 넣었다.
- 이번 평가 API 비용은 약 16달러였다. 이 세션에만 있던 사실(잔액, 누적 비용, 요금제 한도, 결정)을 조사 노트와 평가 폴더 안내서로 옮겼다.
